# 🚀 Mon Premier Projet GitHub

Bienvenue sur mon tout premier dépôt GitHub ! Ce projet sert de point de départ pour apprendre à utiliser Git, gérer des versions de code et découvrir l'univers du développement collaboratif.

## 📋 Description

Il s'agit d'un projet d'apprentissage simple contenant :
1. Ce fichier `README.md` (le guide du projet).
2. Un script Python `main.py` qui affiche un message de bienvenue dynamique.

---

## 🛠️ Comment utiliser ce projet sur votre ordinateur

### 1. Cloner le dépôt
Pour copier ce projet chez vous, ouvrez un terminal et tapez :
```bash
git clone https://github.com/VOTRE-NOM-UTILISATEUR/mon-premier-projet.git
```

### 2. Lancer le script Python
Assurez-vous d'avoir Python installé, puis exécutez :
```bash
python main.py
```
